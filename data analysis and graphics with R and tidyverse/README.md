拆解编程语句的原理，自己写的代码自己一定要懂，比如有些步骤的操作会改变数据结构

从数据科学家的角度学习R，思考如何才能成功地处理、分析和理解数据（获取、整理、注释数据），包括：
A.获取数据（从各种数据源将数据导入程序）；
B.整理数据（编码缺失值、修复或删除错误数据、将变量转换成更方便使用的格式）；
C.注释数据（记住每段数据的含义）；
D.汇总数据（通过描述性统计量了解数据的概况）；
E.数据可视化（一图胜千言）；
F.数据建模（解释数据间的关系，检验假设）；
G.整理数据（创建达到出版品质的表格和图形）

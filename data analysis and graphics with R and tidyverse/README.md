R 是交互式的，最好的学校方法就是自己尝试  

数学、统计学、编程是抽象思维的结晶（函数、映射）

如果你问连个统计学家该如何分析一个数据集，你会得到3个答案

蛇形命名法（snake_case）
驼峰命名法（camelCase）
点分隔命名法（dot.case）

分解子任务
①有序步骤（sequential step）
②分类情况（parallel case）

逻辑测试、取子集、元素方式执行
向量化编程、作用域、S3方法

大多数数据管理都是对数据集进行操作，比如对数据框进行修改，行筛选、列索引

拆解编程语句的原理，自己写的代码自己一定要懂，比如有些步骤的操作会改变数据结构

从数据科学家的角度学习R，思考如何才能成功地处理、分析和理解数据（获取、整理、注释数据），包括：
A.获取数据（从各种数据源将数据导入程序）；
B.整理数据（编码缺失值、修复或删除错误数据、将变量转换成更方便使用的格式）；
C.注释数据（记住每段数据的含义）；
D.汇总数据（通过描述性统计量了解数据的概况）；
E.数据可视化（一图胜千言）；
F.数据建模（解释数据间的关系，检验假设）；
G.整理数据（创建达到出版品质的表格和图形）

在独立的【目录】中保存单个项目是一个好主意，项目中的文件很容易变得越来越多。我建议在项目的主目录下创建几个子文件夹来管理这些文件：
（1）一个 data 文件夹来保存原始数据文件
（2）一个 img 文件夹来保存图片文件以及图形输出文件
（3）一个docs文件夹来保存项目文档
（4）一个reports文件夹来保存报表输出
（5）同时，将R脚本文件与README文件直接保存在【主目录】下
如果这些R文件有顺序要求，那么我会对它们进行编号（比如01_import_data.R、02_clean_data.R等）
README文件是一个文本文件，包含了作者、日期、负责人及其联系方式，以及项目用途等信息。在未来6个月中，【这些信息（README）可以让我知道我做了什么工作以及为什么要做这些工作】

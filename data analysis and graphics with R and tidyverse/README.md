# 由于数据框与分析人员通常设想的数据集的形态较为接近，因此我们在讨论数据框时将交替使用术语列和变量

## ①数据框是一种特殊的列表（list）,其中每个元素就是数据框的一列，且各列具有相同的长度
## ②对数据框的某一列进行操作时，通常会【自动遍历该列的所有元素】，这是R语言向量操作的特性（因为数据框的列本质上是向量）

### 数据框是列表的二维版本，从数据分析角度来看它无疑是最有用的数据存储结构，可以把数据框与Excel表格作对比，二者在数据的存储形式上很相似
### 数据框将向量组织在一个二维的表格之中，每一个向量都是表格中的一列
### 数据框以列为单位组织数据，不同的列可以包含不同的数据类型，数据框中的每一列都必须具有相同的长度




【R的记号体系：1.dataframe[row_index, col_index]→简化：dt[数字]筛选列；2.美元符号与双中括号】
一、索引
R的记号体系可以帮助你从R对象中提取值。例如，要从一个数据框中提取某个值或者某一组值，先写出该数据框的名称，在其后紧跟一对中括号。
deck[ , ]
中括号内有两个索引参数，以逗号分隔。索引参数用来告诉 R 需要提取哪些值。R 用第一个索引参数选择数据框中相应的行（row），用第二个索引参数选择相应的列（column）。
在编写索引时，有多种方式供你选择。对于 R 来说，有六种索引编写方式，每一种在操作上都略有不同：
（1）正整数    【ij记号】
（2）负整数    【排除】
（3）零        
（4）空格      【所有】
（5）逻辑值    【行 / 判别式】♥♥♥♥   ：R 在数据框行维度的每一个位置询问逻辑值索引向量“我是否需要提取第 i 行元素？”，而后咨询逻辑值索引向量的第 i 个逻辑值，如果逻辑值为 TRUE 则提取，如果为FALSE则不提取。要想顺利利用这种索引方式，索引向量的长度必须与待提取元素向量的长度相同（element wise execution）
（6）名称      【列】
二、美元符号（【数据框】或者【列表对象】）与双中括号
在 R 中，有两种对象可以使用第二种记号体系。你【可以用美元符号 $ 提取【数据框】或者【列表对象】中的值】
要想提取数据框的某一列，使用$分隔数据框的名称与想要提取的列的名称。
单中括号 → 列表
双中括号 → 元素值

分类变量（名义变量）和有序的分类变量（顺序变量）在 R 中称为因子（factor）
函数factor()以一个整数向量的形式存储类别值，整数的取值范围是[1...k]（其中K是名义变量中唯一值的个数）。同时，一个由字符串（原始值）组成的内部向量将映射到这些整数上。
【具体赋值根据字母顺序而定】
字符型向量：status <- factor(status, order = TRUE,
                         levels = c("Poor", "Improved", "Excellent"))
数值型向量：sex <- factor(sex, levels = c(1, 2), labels = c("Male", "Female"))
